# Experiments Inventory

## Experiments we'll use

- FLEX-II
- Saffire-II
- FLEX

## What column each experiment includes

- FLEX-II: 
  - Oxygen mole fraction -> Oxygen levels
  - Flow velocity -> Airflow
  - Ambient Gas Mixture
- Saffire-II:
  - Airflow -> Airflow
  - Percent O2 -> Oxygen levels
- FLEX:
  - Fuel -> Material
  - O initial ambient composition; mole fraction -> Oxygen levels

## What column each experiment doesn't have

- FLEX-II: Material / Fuel, Outcome
- Saffire-II: Material / Fuel, Outcome
- FLEX: Airflow, Material / Fuel, Outcome
